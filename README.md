# 🎮 Assembly: EndGame

A fun word-guessing game built with **React** where you have a limited number of attempts to guess the hidden word and save the programming world from Assembly! 😄

## 🚀 Features

- 🎯 Random word selection for every new game
- ⌨️ Interactive on-screen keyboard
- ❤️ Limited number of incorrect guesses
- 🏆 Win and lose game states
- 💀 Languages are eliminated after incorrect guesses
- 🔄 New Game button to restart the game
- 🎨 Dynamic styling based on game status
- ♿ Accessible status updates using ARIA attributes

## 🛠️ Technologies Used

- **React**
- **JavaScript**
- **HTML**
- **CSS**
- **Vite**
- **clsx**

## 🎮 How to Play

1. A random word is selected when the game starts.
2. Click a letter from the on-screen keyboard to make a guess.
3. Correct letters are revealed in the word.
4. Incorrect guesses cause programming languages to be eliminated.
5. You have a limited number of incorrect attempts.
6. Guess the complete word before all attempts are used to win!
7. Click **New Game** to play again.
